# AppChinese — web (Duolingo-style)

Отдельное веб-приложение для изучения китайского в стиле Duolingo: геймификация,
уроки по темам HSK1/2, 7 типов упражнений, SRS-повторение. Работает полностью
на клиенте — весь прогресс хранится в `localStorage`, бэкенд не требуется.

## Стек

React + TypeScript + Vite + Tailwind CSS v4.

## Запуск

```bash
npm install
npm run dev
```

## Сборка

```bash
npm run build   # tsc -b && vite build, результат в dist/
npm run lint
```

## Структура

- `src/data/words.ts` — словарь (иероглиф, пиньинь, перевод, тема, HSK-уровень).
  Добавить новое слово/тему — просто дописать объект в массив `WORDS`.
- `src/data/sentences.ts` — примеры предложений для упражнения "собери фразу".
- `src/data/lessons.ts` — уроки собираются автоматически группировкой слов по теме.
- `src/lib/exercises.ts` — генератор вопросов (7 типов) с дистракторами из всего словаря.
- `src/lib/srs.ts` — упрощённый SM-2 (та же формула, что в `backend/app/srs.py`).
- `src/lib/tone.ts` — определение тона по диакритике, цветовая раскраска пиньиня.
- `src/lib/tts.ts` — обёртка над Web Speech API (браузерный синтез речи, голос `zh-CN`).
- `src/state/ProgressContext.tsx` — глобальное состояние (XP, стрик, жизни, SRS-прогресс
  по словам, достижения), персистится в `localStorage` при каждом изменении.
- `src/screens/` — экраны: Home (карта уроков), Lesson, Results, Profile, Settings.
- `src/components/exercises/` — компоненты для каждого типа упражнения.

## Типы упражнений

1. Выбор перевода (иероглиф → перевод и обратно, в зависимости от направления)
2. Выбор иероглифа по переводу
3. Сопоставление пиньиня (с цветовой подсветкой тонов)
4. Прослушать и выбрать (Web Speech API)
5. Собрать предложение из слов
6. Ввод пиньиня текстом
7. Определить тон на слух (1–4 + нейтральный)

## Геймификация

XP за урок, жизни (5, с восстановлением по времени или мгновенно после урока
повторения), дневная цель, дерево уроков с прогрессивной разблокировкой,
достижения (стрики, количество слов, идеальные уроки), календарь-стрик в профиле.

## Известные ограничения

- Аудио — браузерный TTS (`SpeechSynthesisUtterance`, `lang: 'zh-CN'`), не запись
  диктора; качество и наличие китайского голоса зависят от ОС/браузера пользователя.
- Словарь — стартовый набор ~76 слов по 8 темам (не полные списки HSK1/2 из 450 слов) —
  структура данных рассчитана на то, чтобы легко дополнить.
