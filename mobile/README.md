# AppChinese — mobile

Flutter-клиент MVP: Flashcards (SRS) + Chat (AI-репетитор).

См. общий README в корне репозитория для запуска всего стека:
[`../README.md`](../README.md).

## Разработка

```bash
flutter pub get
flutter analyze
flutter test
flutter build apk --debug
```

Base URL бэкенда настраивается на экране Settings в приложении
(по умолчанию `http://10.0.2.2:8000` для Android-эмулятора).
